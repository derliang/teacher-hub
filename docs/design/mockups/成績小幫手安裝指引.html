INSTALL GUIDE

把成績小幫手網頁版，放到你自己的 Cloudflare

程式安裝在你自己的 Cloudflare 免費帳號，網站與成績資料都只屬於你，不經過任何人的伺服器。全程一行指令，你只需要登入，並自己輸入一組安裝碼。

施工中｜成績小幫手網頁版尚未推出。這份指引先行公開，指令尚未對全新的 Cloudflare 帳號完整實測，實際畫面與文字以你看到的為準。

先知道三件事

  • 你的成績網站是私人的，網址只有你自己和你開通的老師知道；本頁不會列出任何網站網址。
  • 安裝碼是你自己想的一串字（至少 8 個字元，建議 16 個以上），只用來防止別人搶先完成初始化。腳本不會代你產生、讀取、印出或儲存它。
  • Cloudflare 的註冊、登入與同意都由你本人操作；不要把密碼或金鑰貼給任何人。

  1. 1建立 Cloudflare 帳號

    用 Email 註冊，免費方案即可。註冊頁的欄位是 Email、Password，按鈕是 Create Account；Cloudflare 會寄驗證信到你的信箱，依信件完成驗證。

  2. 2取得程式，安裝套件

    取得成績小幫手網頁版的程式資料夾（由管理員提供），電腦需有 Node.js 20 以上。在該資料夾開終端機，執行一次：

    npm install

  3. 3登入 Cloudflare

    執行下面這行，會開瀏覽器，由你本人登入並同意授權。沒登入時後面的指令會卡住不回。

    npx wrangler login

  4. 4執行一行指令部署

    它會自動建立資料庫、產生設定、套用資料庫結構、部署，最後用中文告訴你健康檢查結果。每一步都有說明，中途停下來可以直接重跑，不會重複建立。

    npm run setup

    想先看它會做什麼、完全不連 Cloudflare：

    npm run setup -- --dry-run

    你的資料庫 ID 只會寫進專案資料夾裡的 wrangler.deploy.jsonc，這個檔案不會被上傳到 GitHub。

  5. 5輸入安裝碼，再執行一次

    第一次執行會停在這一步。請照它印出的指令，由你本人輸入安裝碼（輸入時畫面不會顯示），再重跑 npm run setup：

    npx wrangler secret put INSTALL_CODE -c wrangler.deploy.jsonc
npm run setup

    第一次設密鑰時，若問「There doesn't seem to be a Worker called …」要不要建立，答 yes。

  6. 6建立第一位管理者

    腳本最後會印出你的網站網址。照它印的網址，在後面加上 /setup.html 開啟初始化精靈：環境檢查、輸入安裝碼、選「從空白開始」、建立管理者，完成後到登入頁登入。第一位管理者建好之後，別人拿安裝碼也不能再初始化。

健康檢查怎麼看

腳本最後會讀網站的健康檢查並用中文說明。剛部署完，下面兩項不是問題：

  • 「排程尚未執行」：約 10～15 分鐘後才會開始，這段時間顯示未執行是正常的。
  • 「家長查詢網址未設」：只影響通知裡的查詢連結，之後再補即可。

若出現 ✕ 開頭的項目，照腳本印出的中文建議處理後，重跑 npm run setup 即可。

常見問題

  • 要花錢嗎？用 Cloudflare 免費方案即可，日常使用遠低於免費額度。
  • 帳號裡已經有同名資料庫怎麼辦？腳本預設資料庫名稱是 scorekeeper，找得到同名的就沿用；那是別的用途時，加上 --db-name 另取的名字。
  • 怎麼更新到新版？取得新版程式後，再執行一次 npm run setup。
